* cs.DB (Базы данных)
** 🧐 Обзор
За последние сутки наблюдаются два ключевых тренда: дальнейшая интеграция машинного обучения в ядро СУБД с фокусом на устойчивости к "дрейфу" данных и нагрузок, а также развитие систем, упрощающих взаимодействие с базами данных через естественный язык. На практике растёт актуальность методов декомпозиции больших нечётких контекстов для обработки несовершенных данных. Появляются специализированные системы для интеллектуального сбора мультимодальных данных на граничных устройствах.

- [[hxxps://arxiv.org/abs/2512.15742][SHARe-KAN: Post-Training Vector Quantization for Cache-Resident KAN Inference]] — Метод послетренировочного сжатия коэффициентов сплайнов в Kolmogorov-Arnold Networks для эффективного инференса на граничных устройствах.
- [[hxxps://arxiv.org/abs/2604.13433][PackSELL: A Sparse Matrix Format for Precision-Agnostic High-Performance SpMV]] — Новый формат хранения разрежённых матриц PackSELL, поддерживающий гибкие представления данных и ускоряющий SpMV на GPU.
- [[hxxps://arxiv.org/abs/2604.13542][Self-adaptive Multi-Access Edge Architectures: A Robotics Case]] — Предложен подход самоадаптации на основе MAPE-K для распределённой граничной системы, выполняющей задачи ИИ в робототехнике.
- [[hxxps://arxiv.org/abs/2604.14135][Temporary Power Adjusting Withholding Attack]] — Обобщение атаки на майнинг-пулы (T-PAW), демонстрирующее большую прибыльность для мелких майнеров по сравнению с предыдущими атаками.
