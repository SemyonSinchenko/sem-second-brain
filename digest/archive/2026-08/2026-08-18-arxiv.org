* cs.DC (Distributed Computing)
** 🧐 Обзор
За последние сутки наблюдается сильный фокус на оптимизацию распределённого обучения ML-моделей. Ключевые направления включают ускорение тренировки через контроль перегрузок сети, снижение накладных расходов на контрольные точки и синхронизацию без барьеров. Также представлены исследования новых поколений serverless-платформ и протоколов верификации данных перед коммитом в федеративных mesh-архитектурах.

** 🛠 Практика и Системы
- [[hxxps://arxiv.org/abs/2402.09589][MLCC: A Congestion Control Technique to Accelerate ML Training]]
:WHAT: Метод контроля перегрузок, который масштабирует скорость отправки потоков для смещения коммуникации в периоды вычислений (interleaving).
:IMPACT: Ускорение среднего времени итерации тренировки до 1.9x и 99-го перцентиля до 2.7x, уменьшение сетевой конкуренции в GPU-кластерах.

- [[hxxps://arxiv.org/abs/2509.04084][Optimizing Frequent Checkpointing via Low-Cost Differential for Distributed Training Systems]]
:WHAT: Фреймворк повторного использования сжатых градиентов для дифференциальных контрольных точек, устраняющий избыточные вычисления.
:IMPACT: Снижение времени тренировки до 89.2%, возможность контрольных точек каждый шаг итерации без деградации производительности.

- [[hxxps://arxiv.org/abs/2608.13757][A Barrier-Free Synchronization Algorithm for Multi-Engine AI Accelerators]]
:WHAT: Алгоритм синхронизации без барьеров для структурированного управления потоком с вложенными циклами через динамические пороги.
:IMPACT: Снижение задержки на 10-45%, ускорение до 3.3x на синхронизационно-ограниченных бенчмарках для AWS Trainium.

- [[hxxps://arxiv.org/abs/2608.14643][Proof-Gated Publication: Verify-Before-Commit Content Integrity for Serverless Data-Mesh Lakehouses]]
:WHAT: Протокол PVDM с четырьмя фазами (Physical, Verify, Durable, Metadata), блокирующий коммит при провале верификации через keyed multiset hash.
:IMPACT: Блокировка 8000 из 8000 инжектированных ошибок, накладные расходы верификации ~17 мс независимо от размера таблицы.

** 🕸 Графы и Алгоритмы
- [[hxxps://arxiv.org/abs/2607.08244][Self-Stabilizing Algorithms in the Uniform Port Model]]
:ALGO: Самостабилизирующиеся алгоритмы в truly uniform модели с конечными автоматами на портах для задач симметрии (MIS, matching, coloring).
:IMPACT: Первый результат для truly uniform модели с poly-log временем на общих графах, расширяет выразительность за пределы node-centric моделей.

* cs.DS (Data Structures & Algorithms)
** 🧐 Обзор
В cs.DS представлены фундаментальные результаты по lower bounds для графовых streaming-алгоритмов, спектральной кластеризации в высокоразмерных блочных моделях и аппроксимационным алгоритмам для задач связности. Также интересны работы по динамической энумерации в регулярных языках и оптимизации с супермодулярными ограничениями.

** 🕸 Графы и Алгоритмы
- [[hxxps://arxiv.org/abs/2104.04908][Graph Streaming Lower Bounds for Parameter Estimation and Property Testing via a Streaming XOR Lemma]]
:ALGO: Новая техника lower bounds через streaming XOR Lemma для space-pass tradeoffs в оценке параметров графов.
:IMPACT: Доказательство необходимости n^Ω(1) space или Ω(1/ε) passes для (1+ε)-аппроксимации, усиление предыдущих bounds для multi-pass алгоритмов.

- [[hxxps://arxiv.org/abs/2305.00979][Spectral clustering in the Gaussian mixture block model]]
:ALGO: Анализ спектральной кластеризации и embedding для графов из высокоразмерных Gaussian mixture block моделей (d→∞, n→∞).
:IMPACT: Начало картирования information-computation ландшафта для кластеризации в современных сетях с латентными признаками.

- [[hxxps://arxiv.org/abs/2604.00724][Fast Deterministic Distributed Degree Splitting]]
:ALGO: Алгоритм O(ε⁻¹·log n) для balanced orientation и degree splits в LOCAL, связь с hypergraph sinkless orientation.
:IMPACT: Улучшение сложности для (3/2+ε)Δ-edge coloring, совпадение с state-of-the-art для constant ε при Δ=O(2^(log^(1/3) n)).
