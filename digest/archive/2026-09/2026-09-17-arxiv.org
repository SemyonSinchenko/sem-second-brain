* cs.DB
** 🧐 Обзор
За сутки в cs.DB заметен акцент на надёжности распределённых СУБД и на интеграции LLM в текстово-SQL пайплайны. Зрелое направление — тестирование DDBMS через учёт стратегий распределения данных. Практически релевантны также стандартизация гармонизации данных и связывание корпусов с открытыми графами знаний.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2609.18501][Distribution-Aware Distributed Database Testing (Extended Version)]]
:WHAT: DAT/DistRanger — автоматизированное тестирование распределённых СУБД с учётом стратегий шардирования и распределённых оптимизаций, включая мутации запросов с исторической обратной связью.
:IMPACT: 31 ранее неизвестный баг в четырёх продакшн DDBMS; прямой инструмент повышения надёжности распределённых систем обработки запросов.

- [[https://arxiv.org/abs/2406.14163][Crossmaps: standardizing ex-post data harmonization workflows]]
:WHAT: Фреймворк Crossmaps — разделение спецификации и реализации переклассификации агрегатов между стандартами (part-to-whole массив + crossmap), с графовыми, матричными и edgelist-энкодингами.
:IMPACT: Делает ex-post гармонизацию проверяемой и переиспользуемой вместо скрытых ad-hoc скриптов — важно для data engineering и ETL-пайплайнов.

** 🕸 Графы и Алгоритмы
- [[https://arxiv.org/abs/2609.18289][Linking Speakers of the German Parliament to Wikidata: Scope and Coverage of Metadata]]
:ALGO: Методика entity linking всех спикеров Бундестага (1949–2021) к Wikidata с оценкой покрытия и смещений метаданных.
:IMPACT: Показывает практические ограничения открытых графов знаний (пробелы по полу, профессии, транснациональным атрибутам) — полезно при построении KG-приложений.

* cs.AI
** 🧐 Обзор
В cs.AI доминирует тема Text-to-SQL: совместная multi-agent RL-оптимизация (DualSQL) и переосмысление schema linking с новыми LLM. Зреет направление надёжности — атрибуция цитирований и оценка неопределённости. Практическая значимость — совместимость с БД-задачами и агентными системами.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2609.18135][DualSQL: Text-to-SQL with Multi-Agent Reinforcement Learning]]
:WHAT: Двухагентная система schema linking + SQL-генерация на общем бэкбоне с multi-agent RL, guardrail-механизмами и метрикой REX.
:IMPACT: 71.1% execution accuracy на BIRD для 8B модели — превосходит 32B решения; практичный путь к компактным SQL-агентам с доступом к БД.

- [[https://arxiv.org/abs/2408.07702][The Death of Schema Linking? Text-to-SQL in the Age of Well-Reasoned Language Models]]
:WHAT: Пайплайн Text-to-SQL, отказывающийся от schema linking при влезании схемы в контекст; вместо фильтрации — аугментация, селекция и коррекция.
:IMPACT: 71.83% на BIRD (1-е место); пересматривает архитектуру SQL-пайплайнов — меньше преждевременной фильтрации схемы.

* cs.DC
** 🧐 Обзор
cs.DC сегодня целиком про serving LLM и агентных workflow: JCT-ориентированный pipeline parallelism (PipeSwift), физический планировщик Dyserve, иерархическое управление KV-кэшем для diffusion LLM (GroupKV) и адаптивный runtime Libra для RL-посттренинга. Вторая волна — параллельный lexing с сертификатами разбиения и децентрализация durable execution. Практическая значимость максимальна: 1.4–4.2× приросты на реальных GPU-кластерах.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2609.16491][PipeSwift: Revisiting Pipeline Parallelism for Large-Scale Completion-Oriented Agentic LLM Serving]]
:WHAT: Pipeline-parallel runtime, переориентированный с token-SLO на job completion time: JCT-aware планирование + pipeline-интегрированный multi-token prediction.
:IMPACT: До 1.45× снижение JCT против SGLang wide-EP и 1.54× против state-of-the-art PD-disaggregation на 64 H800 — напрямую улучшает стоимость агентного serving.

- [[https://arxiv.org/abs/2607.02942][Serving Agentic Workflows with a Physical-Plan Compiler and Adaptive Runtime]]
:WHAT: Dyserve — слой физического планирования между оркестрацией и serving: компилятор выбирает модель/верификатор/бэкенд на узел, runtime переключает варианты по давлению на бэкенды.
:IMPACT: +3–9 п.п. точности с ускорением latency до 6.8×; корректно-вовремя завершённые запросы растут с 18.1% до 67.2% при burst-нагрузке.

- [[https://arxiv.org/abs/2606.03077][Libra: Efficient Resource Management for Agentic RL Post-Training]]
:WHAT: Адаптивный runtime для agentic RL: bucket-планировщик rollout с guided causality + динамическое перераспределение воркеров между rollout и training через non-blocking протокол.
:IMPACT: До 4.2× throughput на кластерах A800/Ascend — снижает стоимость RL-посттренинга агентных LLM.

- [[https://arxiv.org/abs/2609.17573][GroupKV: Hierarchical KV Cache Management for Long-Context Diffusion LLM Inference]]
:WHAT: Иерархическое управление KV-кэшем для dLLM: групповая sparse-селекция, предиктивный prefetching по cross-layer консистентности, streaming prefill.
:IMPACT: До 48× увеличение обслуживаемого контекста и 3.73× ускорение при offload — ключевое для длинноконтекстного dLLM-инференса.

- [[https://arxiv.org/abs/2608.03473][Certified Split Points for Parallel Lexing]]
:WHAT: Символы с сертификатом безопасного разбиения входа для параллельного lexing без симуляции/перекрытия, проверяемые за O(1) по таблицам DFA.
:IMPACT: 92.6–95.3% параллельной эффективности на 8 потоках; превращает параллельный lexing из языкового допущения в проверяемое свойство компилятора.

- [[https://arxiv.org/abs/2608.09761][Certified Split Windows for Parallel Lexing: Recovering Boundaries Where No Byte Certifies]]
:WHAT: Обобщение сертификатов с байта на окно: восстанавливает начало токена там, где ни один байт не сертифицируется, через точный анализ достижимых конфигураций сканера.
:IMPACT: 322 из 337 «безнадёжных» наборов токенов получают окна разбиения — расширяет применимость параллельного lexing на реальные языки (JSON, C-подобные).

- [[https://arxiv.org/abs/2609.17645][State Without a Landlord: Peer-to-Peer Replication of Durable Workflow State]]
:WHAT: Архитектура P2P-репликации журналов durable execution: single-writer epoch cores, quorum-finalized closure certificates, content-addressed payload plane.
:IMPACT: Убирает зависимость durable workflow от провайдера-«арендодателя» — шаг к портируемому и цензурностойкому stateful serverless.

- [[https://arxiv.org/abs/2510.04478][Overlapping Schwarz Scheme for Linear-Quadratic Programs in Continuous Time]]
:WHAT: Optimize-then-discretize декомпозиция Шварца для LQ-задач оптимального управления с перекрывающимися временными интервалами и доказанной сходимостью через экспоненциальное затухание чувствительности.
:IMPACT: Параллелизация задач управления без фиксации интегратора — применимо к scientific computing и model predictive control.
