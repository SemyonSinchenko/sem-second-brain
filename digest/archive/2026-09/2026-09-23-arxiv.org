* cs.DB — Базы данных
** 🧐 Обзор
За сутки в cs.DB заметен сдвиг к дисциплине оценки: стенд без утечек для классификации закупок показывает, что «протекающие» сплиты не просто сглаживают метрики, а скрывают реальные различия моделей. Автоматизация NL2SQL движется от ручной подготовки примеров к систематической генерации контекста по query flows с продакшен-деплоем на 50+ базах. Под регуляторным давлением EU/US зреет инфраструктура аудируемого обмена данными, а текст становится связующим звеном интеграции таблиц в data lakes.
** 🛠 Практика и Системы

  :WHAT: Стенд с четырьмя leak-free протоколами на 1,26 млн размеченных строк закупок; вскрывает, что случайные сплиты содержат до ~61% повторяющегося текста, и выводит верхнюю границу точности текстовых классификаторов из противоречивых меток на идентичных текстах.
  :IMPACT: На чистых протоколах трансформер обгоняет retrieval на 2,3–3,6 п.п., тогда как утечка это маскирует; стенд уже в продакшене (деплой на 920 927 строк) — прямой эталон для enterprise spend analytics.

  :IMPACT: Снимает cold start для новых баз и постоянную нагрузку по поддержке примеров при эволюции схем; развёрнуто на 50+ реальных БД в Tursio.
- [[https://arxiv.org/abs/2609.26654][Proof-of-Retention: A Framework for Auditable Cross-Organization Data Sharing]]
  :WHAT: Фреймворк и интерактивный протокол аудируемого data sharing: стороны удерживают подмножество информации по каждому обмену, аудиторы криптографически проверяют retention через query witnesses и proof-of-possession.
  :IMPACT: Практичный комплаенс под новые режимы EU/US без полной репликации данных и навязчивого мониторинга; есть референс-реализация на AWS.

  :WHAT: Архитектура LOKI (горизонтальная бидирекционная cross-attention) для Text-Mediated Join Path Discovery: контрастирование «таблица–текст» порождает связи строк через конкретные предложения без локальной разметки, с материализацией типизированных таблиц и sentence-level провенансом.
  :IMPACT: Macro typed-pair precision 0.982 и в ~40× дешевле прямого промптинга LLM — шаг к автономной интеграции семантически связанных, но структурно разрозненных таблиц в data lakes.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2510.15596][PRISM: Probabilistic Runtime Insights and Scalable Performance Modeling for Large-Scale Distributed Training]]
  :WHAT: Вероятностная модель производительности распределённого обучения: композиция распределений латентностей операторов по зависимостям workload с явным учётом стохастики (наблюдается 12% вариативности уже на 64K+ GPU).
  :IMPACT: Ошибка оценки p95 в пределах 5,4% на 14 конфигурациях от сотен до 64K+ GPU; вариативность-осознанные рекомендации по дизайну и оптимизации тренировок.
- [[https://arxiv.org/abs/2512.21835][LOIP: Collaborative Lossless LLM Inference Serving with Offloading-based Pipeline Parallelism on Edge Devices]]
  :WHAT: Lossless LLM-инференс на edge: offloading-aware cost model, планировщик разбиения слоёв, UMA-aware загрузка через кастомные CUDA-операторы и онлайн-адаптация памяти под давление KV-кэша и флуктуации полосы.
  :IMPACT: Ускорение 8,8–20,3× против SOTA на пяти разнородных NVIDIA Jetson при инференсе LLaMA3.3-70B без потери точности.
- [[https://arxiv.org/abs/2609.15558][Opportunistic ZGC: Leveraging Idle Cores for More Effective Concurrent Garbage Collection]]
  :WHAT: Feedback-directed политика планирования ZGC в HotSpot: динамическое сдерживание heap и запуск конкурентных сборок на недогруженных CPU-ядрах, без per-application тюнинга.
  :IMPACT: Снижение максимального heap на 61–90% на DaCapo Chopin при минимальном влиянии на throughput и латентность — экономия памяти для latency-critical Java-сервисов.
- [[https://arxiv.org/abs/2609.18886][Fluid Notarization: Verifiable Evolution of Concurrently Edited Structured Documents]]
  :WHAT: Нотаризация эволюции документов: JSON-нативный delta-CRDT (на базе Melda) порождает граф причинно связанных дельт; в блокчейн пишутся только идентификаторы артефактов, а синхронизация, реконструкция и разрешение конфликтов остаются off-chain.
  :IMPACT: Детерминированная сходимость CRDT плюс независимо аудируемые proof-of-existence, provenance и publication без снапшотов — прототип на совместно редактируемых электронных медкартах.
- [[https://arxiv.org/abs/2609.19024][OAK: Restart- and Age-Aware Scheduling for Distributed Machine Learning on Shared GPU Clusters]]
  :WHAT: Per-round MILP-планировщик для shared GPU-кластеров: к goodput добавлены «возраст» задачи (накопленное ожидание) и декомпозированный restart-фактор (полезное время обучения и оверхед чекпоинтов как раздельные величины).
  :IMPACT: При отказах с интенсивностью λ=0,1 — снижение среднего JCT на 33,9–58,3% и хвостового на 58–76%; решение за 7,65 мс, на три порядка быстрее эволюционного поиска.
- [[https://arxiv.org/abs/2609.25442][WeightBridge: An Efficient Weight Transfer Library for Reinforcement Learning]]
  :WHAT: Библиотека передачи весов trainer→rollout для RL-систем: автоматическое извлечение соответствия раскладок весов, планирование без избыточности и с балансировкой, разные режимы синхронизации через компактный API.
  :IMPACT: До 42× меньше среднего GPU-столла против SOTA open-source RL-фреймворка; coding agent интегрировал её в два RL-фреймворка без ручного вмешательства — готово к встраиванию в RL-стеки для LLM.
** 🕸 Графы и Алгоритмы
- [[https://arxiv.org/abs/2411.02560][Fast and Robust Information Spreading in the Noisy PULL Model]]
  :ALGO: Квази-самостабилизирующийся протокол на 2-битных сообщениях в шумном PULL(h): оптимальное время схождения к majority-мнению источников O((n/h) log n) с высокой вероятностью (O(log n) при h=Θ(n)); ключевой подпротокол «слушай — затем усиль» на 1 бите.
  :IMPACT: Надёжная диссеминация в шумных, несинхронизированных и неуправляемых системах (биовдохновленные рои, сенсорные сети) при минимальном размере сообщений.
