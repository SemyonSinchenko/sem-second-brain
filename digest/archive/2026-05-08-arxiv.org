* cs.DB (Databases)
** 🧐 Обзор
В последние сутки наблюдается сильный тренд на оптимизацию метауправления и улучшение производительности запросов в гетерогенных средах. Исследователи фокусируются на создании расширяемых языков для переписывания запросов и снижении задержек при поиске ближайших соседей за пределами оперативной памяти. Также заметен рост интереса к автоматизации очистки данных временных рядов с помощью агентов на основе обучения с подкреплением.

** 🛠 Практика и Системы
- [[hxxps://arxiv.org/abs/2605.05536][An Extensible and Verifiable Language for Query Rewrite Rules]]
:WHAT: Домен-специфичный язык Rulescript для формально верифицируемых правил переписывания запросов, независимый от движка исполнения.
:IMPACT: Позволяет реализовать подход "write once, deploy everywhere" для оптимизации планов запросов, снижая затраты на инженерию и портацию между СУБД.
- [[hxxps://arxiv.org/abs/2605.05787][Low-Latency Out-of-Core ANN Search in High-Dimensional Space]]
:WHAT: Гибридный метод SkipDisk для поиска ближайших соседей, сочетающий дисковое хранение с эффективной фильтрацией в памяти.
:IMPACT: Достигает задержек, сравнимых с индексами в памяти (HNSW), при значительном уменьшении footprint, что критично для больших векторных баз.

** 🕸 Графы и Алгоритмы
- [[hxxps://arxiv.org/abs/2605.04902][AegisTS: A Hierarchical Agent System with Reinforcement Learning for Multivariate Time Series Data Cleaning]]
:ALGO: Иерархическая система агентов с RL для совместной оптимизации порядка устранения ошибок качества данных и выбора моделей очистки.
:IMPACT: Позволяет эффективно обрабатывать множественные ко-оккурентные проблемы качества данных без опоры на размеченную ground truth.

** 📄 Остальное
- [[hxxps://arxiv.org/abs/2409.05512][DatAasee -- A Metadata-Lake as Metadata Catalog for a Virtual Data-Lake]] — Предложена архитектура metadata-lake для агрегации метаданных распределенных источников в исследовательских средах.

- [[hxxps://arxiv.org/abs/2412.09125][Goal-Driven Query Answering over First- and Second-Order Dependencies with Equality]] — Техника ответвления запросов для зависимостей первого и второго порядка, ускоряющая вычисление универсальной модели.
