* cs.DB (Databases)
** 🧐 Обзор
В последние сутки наблюдается сильный тренд на интеграцию криптографической защиты данных непосредственно в引擎ы запросов, что позволяет выполнять сложную analytics без раскрытия информации. Параллельно развивается направление исправления и генерации SQL через специализированные LLM, а также индексация для гибридных запросов с интервальными предикатами. Эти работы делают акцент на практической применимости приватных вычислений и улучшении качества текстовых интерфейсов к данным.

** 🛠 Практика и Системы
- [[hxxps://arxiv.org/abs/2509.10793][ORQ: Complex Analytics on Private Data with Strong Security Guarantees]]
:WHAT: Система для collaborative analysis частных数据集 используя secure multi-party computation (MPC) с оптимизацией joins.
:IMPACT: Позволяет выполнять сложные relational queries с агрегациями под MPC без quadratic cost, масштабируясь до TPC-H SF10.
- [[hxxps://arxiv.org/abs/2603.03742][ErrorLLM: Modeling SQL Errors for Text-to-SQL Refinement]]
:WHAT: Framework для explicit modeling ошибок в generated SQL queries через dedicated error tokens.
:IMPACT: Значительно повышает точность refinement SQL запросов, устраняя hallucination и improving detection precision.

** 🕸 Графы и Алгоритмы
- [[hxxps://arxiv.org/abs/2606.24204][Unified Dominance Graph for Interval-Predicate Approximate Nearest Neighbor Search]]
:ALGO: Graph-indexing framework (UDG) для Interval-Predicate ANNS, mapping endpoints в dominance space.
:IMPACT: Позволяет эффективно обрабатывать hybrid queries с interval constraints (time, price) без overhead intersection.
- [[hxxps://arxiv.org/abs/2606.22419][Knowledge-Graph Grounding Helps LLMs Only for Out-of-Training Knowledge]]
:ALGO: Controlled study использования graph+vector engine для grounding LLM в clinical QA.
:IMPACT: Demonstrates that KG grounding помогает только для facts outside training data, критично для design retrieval systems.

** 📄 Остальное
- [[hxxps://arxiv.org/abs/2606.09824][TSseek: Regular Expression-Based Similarity Search for Distributed Time Series Datasets]] — Framework для pattern-based search в time series через regular expressions и spatial index.
- [[hxxps://arxiv.org/abs/2606.23875][On the Semantics of Generative SPARQL]] — Extension SPARQL с generative query construct (GenOp) maintaining fixed-dataset assumption.
