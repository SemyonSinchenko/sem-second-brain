* cs.DB — Базы данных

** 🧐 Обзор
За сутки в cs.DB доминируют системы поверх зрелых движков: семантические операторы в расширенной реляционной алгебре (NousDB) и планировщик Range-GET-запросов для векторного поиска прямо на объектных хранилищах (WaRP). Продолжает зреть тема графовых path-запросов в реляционных СУБД — абстракция ReCAP позволяет DuckDB обгонять state-of-the-art графовые и реляционные СУБД до 400000x. Второй устойчивый тренд — верифицируемость: конструктивные доказательства эквивалентности SQL-переписываний (EquiTrace) и проверяемое распределённое дифференциальное privacy (VDDP). Платформа Ozone подтверждает спрос на унификацию гетерогенных доменных данных.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2610.28551][NousDB - A Fast Query Engine for Semantic Analytics]]
  :WHAT: Высокопроизводительный движок семантической аналитики на Apache DataFusion: расширенная реляционная алгебра с тремя семантическими операторами, формальные алгебраические свойства для переписывания запросов и token-based модель стоимости (equi-depth гистограммы токенов) для безопасного батчинга под context window.
  :IMPACT: Существенные ускорения с локальными и enterprise LLM при лидерстве по token-эффективности и точности; приросты сохраняются на JOB и Stack с семантическими операторами — практичная база для LLM-аналитики в SQL-подобном стиле.

- [[https://arxiv.org/abs/2610.29689][WaRP: Workload-Aware Request Planning for Vector Retrieval on Object Storage]]
  :WHAT: Планировщик запросов для кластерных ANN-индексов на объектном хранилище: объединение Range-GET по исследованным кластерам формулируется как глобальная per-query оптимизация; оптимизированное динамическое программирование и adaptive frontier search дают (1+ε)-оптимальный план за <10 мс, плюс офлайн-реордеринг байтовых интервалов.
  :IMPACT: Встроено в I/O-планировщик Lance на AWS S3 (SIFT100M, DEEP100M и др.): QPS ×1.09–3.48 и в 2.12–5.19 раза меньше GET-запросов при сохранении recall — прямой эффект на латентность и счёт за запросы.

- [[https://arxiv.org/abs/2604.02553][Efficient Path Query Processing in Relational Database Systems]]
  :WHAT: ReCAP — абстракция ранней фильтрации property-ограничений при вычислении path-запросов: достаточно реализовать NFA-подобную функцию переходов и несколько функций в духе user-defined aggregates, чтобы реляционный оптимизатор проталкивал ограничения глубоко в план.
  :IMPACT: DuckDB с ReCAP обгоняет state-of-the-art графовые и реляционные СУБД до 400000x — практический путь исполнять графовые path-запросы без специализированного графового движка.

- [[https://arxiv.org/abs/2610.30100][Building SQL Equivalence Proofs from Query Rewrite Rules]]
  :WHAT: EquiTrace — система, превращающая правила переписывания SQL в доказательства эквивалентности: разделяет валидацию правил и поиск доказательств, выравнивает альтернативные представления запросов и возвращает воспроизводимую деривацию.
  :IMPACT: Доказывает 86.1% курируемых пар и 97 переписываний против 35–38 у QED/SQLSolver — готовый инструмент для тестирования оптимизаторов и верификации text-to-SQL.

- [[https://arxiv.org/abs/2504.21752][VDDP: Verifiable Distributed Differential Privacy under the Client-Server-Verifier Setup]]
  :WHAT: Фреймворк верифицируемого исполнения распределённых DP-механизмов против (в т.ч. сговоренных) клиентов, серверов и верификаторов; инстанциация VDDLM — распределённый дискретный лапласовский механизм с ускорением доказательства в 50x–4 000 000x.
  :IMPACT: Закрывает реальную уязвимость «нечестного» сервера, семплирующего шум из неверных распределений, — основа для доверенных DP-деплоев в распределённых системах.

- [[https://arxiv.org/abs/2604.10959][Ozone: A Unified Platform for Transportation Research]]
  :WHAT: Единая платформа транспортных исследований со слоями Hardware/Data/Model/Evaluation: общая траекторная схема, конвертеры для 19 датасетов с 59 площадок в восьми странах, связь с CARLA digital-twin картами и SUMO.
  :IMPACT: Сокращение времени настройки экспериментов на 85% и воспроизводимый кросс-датасетный бенчмаркинг — готовая инфраструктура для траекторных и событийных данных.

** 🕸 Графы и Алгоритмы
- [[https://arxiv.org/abs/2412.09411][Resilience for Regular Path Queries: Towards a Complexity Classification]]
  :ALGO: Классификация регулярных языков по вычислимости resilience RPQ над графовыми БД: трактабельность для локальных языков, hardness в data complexity для конечных языков с повторами и «четырёхногих» языков, дихотомия для языков с нейтральным символом.
  :IMPACT: Определяет, когда минимальное число удаляемых фактов, делающее path-запрос ложным, считается эффективно — база для диагностики устойчивости графовых запросов и работы оптимизаторов.

* cs.AI — Искусственный интеллект

** 🧐 Обзор
За сутки в cs.AI почти все обновления — replace, но отчётлив тренд на связку LLM со структурированными данными: GRAB поднимает реляционные таблицы в гетерогенный граф для multi-table QA, а BiasGuard-D трактует LLM-записи как данные с аудируемым качеством в продуктивных системах. Зреет измерение «за пределами accuracy»: Rule Violation Score автоматически превращает Хорновы правила в SQL-проверки логической согласованности моделей, включая link prediction по knowledge graph. Для системщиков практически значима первая демонстрация удалённой Rowhammer-атаки на FL-сервер через манипуляции клиентскими наблюдениями.

  :IMPACT: На бенчмарках KG link prediction и реляционной регрессии модели с равной точностью радикально расходятся по логической согласованности — дешёвый SQL-инструмент контроля качества продуктивных пайплайнов.

  :IMPACT: Аудируемый provenance-трейл для LLM-записей в информационных системах (под новые AI-регуляции); перенос между задачами со сменой ролей даёт +49 п.п. восстановления правильных ответов на HaluEval QA.

  :IMPACT: Новая поверхность атак для FL с sparse-обновлениями и RDMA — аргумент за системные и аппаратные митигации в FL-инфраструктуре.

* cs.DS — Алгоритмы и структуры данных

** 🧐 Обзор
Сутки в cs.DS закрывают давние сюжеты: доказана оптимальность бинарного дерева механизма для DP continual counting (Ω(log^{3/2} n) при approximate и Ω(log² n) при pure DP), а кластер из трёх работ зафиксировал точные константы схемы округления Wang–Sitters для graph balancing (supremum 11/6, минимальный свидетель разрыва 3/2). Практически значимы линейный алгоритм наибольшего набора рёберно-непересекающихся устойчивых паросочетаний, динамический k-center с «временами жизни» и упрощение потокового аукционного алгоритма для двудольных паросочетаний. Чисто теоретическая работа о де-Хёльдеровских факторизациях неожиданно даёт улучшенные вершинные cut-спарсификаторы взвешенных графов.

** 🕸 Графы и Алгоритмы
- [[https://arxiv.org/abs/2011.13248][Disjoint Stable Matchings in Linear Time]]
  :ALGO: Алгоритм линейного от размера входа времени, строящий наибольшее множество попарно рёберно-непересекающихся устойчивых паросочетаний; плюс перечисление максимальных цепей в решётке устойчивых паросочетаний и NP-полнота различения «≤2 vs ≥3» для Stable Roommates.
  :IMPACT: Расширяет классику Гейла–Шепли от «двух крайних» матчитингов к максимальному переиспользованию рёбер — полезно для декомпозиции нагрузок в матчинговых платформах и распределении ресурсов.

- [[https://arxiv.org/abs/2607.07439][On the Assadi Liu Tarjan Auction Algorithm for Bipartite Matching: Simplification, Alternative Analysis, and Hard Instance]]
  :ALGO: Показано, что механизм «заморозки» перевыбранных вершин в (1−ε)-аппроксимационном аукционном алгоритме избыточен; дано новое доказательство через увеличивающие пути и построен первый трудный экземпляр (простой путь) с Ω(1/ε²) итерациями.
  :IMPACT: Упрощает реализацию state-of-the-art компромисса passes/approximation в multi-pass streaming — прямой кандидат для потоковых матчинг-подсистем.

- [[https://arxiv.org/abs/2603.23348][Dynamic k-center clustering with lifetimes]]
  :ALGO: Новая модель «времён жизни» между sliding window и fully dynamic: детерминированный (2+ε)-аппроксимационный алгоритм с Õ(k/ε) амортизированным апдейтом и (6+ε)-аппроксимация с сильно сублинейной памятью для «приручённых» последовательностей обновлений.
  :IMPACT: Практичная кластеризация потоков, где время устаревания точки известно заранее (сенсоры, сессии) — компромисс память/качество для data summarization.

- [[https://arxiv.org/abs/2609.07564][De-Höldering factorization]]
  :ALGO: Конструктивные факторизации Липшицевых функций через «де-Хёльдеровские» преобразования; следствия — расширение L1-функций с подмножеств ℓ2 на всё ℓ2 (ответ на вопрос Ball 1992) и вершинные cut-спарсификаторы размера n и качества O(√log n) для взвешенных графов.
  :IMPACT: Улучшает границу Мойтры 2009 — более компактные спарсификаторы разрезов, напрямую влияющие на sketches графов в потоковых и распределённых настройках.

** 📄 Остальное

* cs.DC — Распределённые вычисления

** 🧐 Обзор
Сутки в cs.DC прошли под знаком LLM-инфраструктуры: NanoCP балансирует KV-кэш и батчи через динамический context parallelism, KVLearn учится решать, какой KV-кэш удерживать в disaggregated serving, а MCCL замыкает контур «измерение → перепланирование» коллективных коммуникаций при «серых» отказах (до 4.99x ускорения обучения). Зреет CPU-инференс тернарных LLM: главный резерв — синхронизация между NUMA-узлами, а не размещение весов. Системно значимы также верифицируемая межчейн-интероперабельность XIR (reachability 14.64%→96.86%), концепт-основанные C++-биндинги MPI (KaMPIng-v2) и sketch-агрегация федеративного LoRA.

** 🛠 Практика и Системы
