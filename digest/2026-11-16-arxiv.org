* cs.DB — Базы данных

** 🧐 Обзор
Основная линия последних суток — инфраструктура векторного поиска: единый graph-vector движок Samyama вышел на миллиардный масштаб с воспроизведёнными замерами, KatoANN приблизил векторный поиск к скорости lossy-сканов на CPU-матричных движках, а HVMap и ResGraph закрывают эксплуатационные проблемы — федерацию разнородных vectorDB и миграцию графовых индексов при смене embedding-модели. Зреет генеративный поиск: GenTUS заменяет pipeline «embed — search — refine» порождением семантических идентификаторов таблиц. Практический эффект везде одинаковый: меньше ETL, меньше пере-индексации и дешевле смена моделей в проде.

** 🛠 Практика и Системы
- [[https://arxiv.org/abs/2603.08036][Samyama: A Unified Graph-Vector Database with In-Database Optimization, Agentic Enrichment, and Hardware Acceleration]]
:WHAT: Единый Rust-движок (RocksDB+MVCC, vectorized executor, cost-based planner, CSR-аналитика, RDF/SPARQL, HNSW, 22 метаэвристических солвера из языка запросов, LLM-обогащение графа), проверенный на 74.3M узлов и 1.07 млрд рёбер на одной машине за $2.50 spot-вычислений.
:IMPACT: Убирает ETL между графовыми БД, векторными сторами и солверами; на SNB SF10 7 из 14 complex reads быстрее Neo4j 5 и FalkorDB, conformance openCypher доведён до 99.9% — прямая альтернатива стеку из нескольких систем.

- [[https://arxiv.org/abs/2607.00833][GenTUS: Table Union Search via Constrained Generation of Semantic Table Identifiers]]
:WHAT: Генеративный retrieval для Table Union Search: компактные идентификаторы таблиц, обученные под pairwise unionability, и prefix-constrained beam search вместо поиска по векторному индексу с реранкингом.
:IMPACT: Лучшее качество на 7 бенчмарках при существенно меньшем времени online-поиска и объёме артефактов — важно для data lake discovery, где候选ный пул на каждый запрос слишком дорог.

- [[https://arxiv.org/abs/2609.23036][ResGraph: Cross-Model Graph-based Index Migration via Residual Reachability in ANN Search]]
:WHAT: Миграция graph-based ANN-индексов между моделями эмбеддингов через «остаточную достижимость»: Res-Local (параллельное shallow-расширение с фильтрацией second-hop кандидатов) и Res-Search (beam-обход с ограничением по хопам).
:IMPACT: До 17.4x ускорения построения нового индекса при конкурентном recall — снимает главный операционный барьер переезда на новые embedding-модели.

- [[https://arxiv.org/abs/2610.27508][KatoANN: Enabling Near-Exact Vector Search at the Speed of Lossy Scans with CPU Matrix Engines]]
:WHAT: Первая ANN-система для CPU matrix engines (Intel AMX): 16-битные коды векторов, разбиение на high/low-byte плоскости и near-exact расстояния через 8-битные матричные умножения с ранжированием кандидатов по high-bytes.
:IMPACT: Высокий recall при throughput lossy-сканов и меньший memory footprint (без full-precision копий) — дешёвый векторный поиск на CPU без GPU.

- [[https://arxiv.org/abs/2611.01514][Federated Vector Retrieval across Heterogeneous VectorDBs]]
:WHAT: HVMap — лёгкий compatibility-слой для федеративного поиска: bidirectional отображения между пространствами эмбеддингов через fuzzy contrastive loss и hub-архитектура для мульти-vectorDB-сетапов.
:IMPACT: До 3.59x выше nDCG@10 и 2.01x выше throughput при времени построения 0.3% от baseline — федерация без corpus-wide re-embedding и перестройки индексов.

- [[https://arxiv.org/abs/2611.11295][Samyama-SDG: A Declarative GraphQL @count and Regex/Ontology Synthetic Data Compiler with O(1)-Memory Referential Integrity and Causal Ground Truth]]
:WHAT: Rust-компилятор синтетических данных: Cardinality-Extended GraphQL-схемы компилируются в DAG, а seekable PRNG с index-bijective первичными ключами дают O(1)-память для referential integrity плюс онтологически связанные каузальные ground-truth метки.
:IMPACT: 5.8–7.76M строк/с при плоских 31–35 MiB памяти и нуле ошибок на 1.15 млн внешних ключей — практичный генератор тестовых данных для системных бенчмарков.

* cs.AI — Искусственный интеллект

:IMPACT: 6–30% экономии токенов и в 3–19x меньший overhead относительно Palimpzest и Quest — делает семантические SQL-запросы над большими корпусами экономически оправданными.

:IMPACT: Первый токен за 1.5 s против 291–612 s у llama-server/Ollama при 8 параллельных агентах; 10 656 tok/s на 12 Mac Studio M3 Ultra — практичная локальная инференс-инфраструктура для команд.

:IMPACT: Первая воспроизводимая площадка для оценки агентной kernel-оптимизации под реальные LLM-workloads на NPU — приросты на бенчмарке отображаются в реальные пайплайны.

* cs.DS — Структуры данных и алгоритмы

В системной части — Express, превращающий non-causal attention-приближения в причинные с I/O-aware Triton-реализацией, и адаптивная дифференциально-приватная power iteration с beyond-worst-case гарантиями.

:IMPACT: Существенные ускорения против FlashAttention 2 и снятие четырёх ресурсных узких мест LM-пайплайна (long-context prefill, сжатие KV-кеша, memory- и compute-ограниченный decoding) — прямая системная ценность для инференса.

:IMPACT: Лучшие гарантии на типичных low-coherence данных (включая i.i.d.) — практичная приватная аналитика признаков без штрафов худшего случая.
